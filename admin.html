🛟 Data Tools

Rebuild Player Stats from Game History

Every finished game keeps its own complete box score in Game History, independent of the season-long player totals. If those totals ever get out of sync (a device saving before it finished loading, a roster change, etc.), use this to recompute them from scratch by re-adding up every saved game — rather than trying to patch numbers by hand.

Edit / Add a Box Score

For any saved game — including ones added manually with just a final score — type in each player's stats directly. Saving updates that game's box score and automatically resyncs everyone's season totals.

Backfill Missing Game Weeks

If a saved game shows up as "Week TBD" on the player Game Film page, it means its schedule entry never got marked final — usually because the game was started with home/away swapped from how the schedule listed it. This finds any saved game missing a week, matches it to the schedule (checking both team orders), and fixes both.

Edit a Saved Game's Box Score

The real fix for a scoring mix-up — moves a stat between two players within that specific saved game, not just the season total. Automatically re-rebuilds season totals afterward, so everything (this game's box score, the player pages, Overall rankings) stays consistent in one step.

Merge Player Stats

When someone's jersey number changes, their old stats get stuck under the old number as a "Former Player" instead of following them. Use this to fold those old stats into their current entry — sums everything together (points, rebounds, game log, etc.) and removes the old duplicate.

MERGE STATS FROM (old/former entry)
INTO (current roster player)

Transfer Stats

Fixes a scoring mix-up — e.g. a basket that was logged under the wrong player. Moves a specific amount of one stat from one current player's season totals to another's. This only adjusts season totals, not the original saved game's box score, so re-running "Rebuild from Game History" later would undo this — use Rebuild first if you need both.
